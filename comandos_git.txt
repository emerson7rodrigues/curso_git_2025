git .ini -> torna a pasta um repositório Git
git status -> mostra o status do trabalho
git add -> adicionar arquivos para versionamento
git commit -m msg" -> faz commit do que stara para ser 
git add nome_arquivo -> adiciona arquivo para ser commitado
git log -> mostra todo o histórico de commits

FLUXO DE TRABALHO
1- Criar o diretório do projeto
2- Iniciar o git dentro do diretório criado (git init .)
3- Editar ou criar arquivos
4- git status
5- git add <nome arquivo>
6- git status
7- git commit -m "mensagem"
8- git status
9- Volta ao passo 3
